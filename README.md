# 个性化工作站（项目总入口）

本目录是这个项目的唯一工作目录。开发时以 `初版PRD.md` 为准：代码与文档冲突时，先改文档再改代码。

## 目录里有什么

| 路径 | 说明 |
| --- | --- |
| `初版PRD.md` | 产品需求文档 v1.0，**开发的唯一依据**（计科版 11 个模块 + 数据与设置、各模块字段与操作、验收标准） |
| `界面设计验收.html` | 界面设计验收稿：单文件，浏览器直接打开就能点着核对（右上角「验收清单」19 条） |
| `界面与交互设计-v1.md` | 早期设计稿（模块清单已过时，仅作历史参考，不作为开发依据） |
| `个性化工作站-源码/` | WPF 工程源码（.sln + .csproj + .vscode + publish.ps1） |
| `个性化工作站/` | 已发布的成品：双击 `PersonalWorkstation.exe` 即可运行，`data/` 是数据 |
| `QA.txt` | 最初一轮需求原文（模块清单已被计科版取代，仅作历史） |
| `工作生活软件“个性化工作站”-….md` | 上一轮对话的导出记录，仅供追溯，不作为开发依据 |

## 模块清单（计科版：11 个模块 + 数据与设置）

| 分组 | 模块 |
| --- | --- |
| 置顶 | 首页总览 |
| 学习事务 | 今日计划、课程与作业 |
| 开发实战 | 项目实战、刷题算法 |
| 升学求职 | 实习求职、竞赛与证书 |
| 技术输出 | 技术输出 |
| 生活健康 | 健身计划、饮食计划、游戏娱乐 |

导航栏「首页总览」这一行的右端是折叠 / 展开按钮（展开 `‹`，折叠后 `›`）；导航栏右边界可用鼠标拖动改宽（180 ~ 420px，双击恢复默认 236px）。第一版不新增快捷键，沿用 `Ctrl+1` ~ `Ctrl+9`（只覆盖前 9 个模块）。

## 怎么跑起来

```powershell
# 直接跑源码（调试用，数据写到 .dev-data）
dotnet run --project .\个性化工作站-源码\PersonalWorkstation\PersonalWorkstation.csproj

# 编译并发布 exe 到 .\个性化工作站
.\个性化工作站-源码\publish.ps1
```

也可以用 Visual Studio 2022 / VS Code 打开 `个性化工作站-源码\PersonalWorkstation.sln` 按 F5。

自检（不需要人工点界面）：

```powershell
.\个性化工作站\PersonalWorkstation.exe --data-dir .\.selftest-tmp --selftest .\.selftest-tmp\报告.txt
```

## 不变的前提

- 只本机、只本人：不登录、不联网、不云同步、不做手机端。
- 不引入任何第三方 NuGet 包，全部用 .NET 自带能力。
- 数据只落在程序目录的 `data\工作站数据.json`，整个文件夹拷走就是完整备份。
