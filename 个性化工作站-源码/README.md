# 个性化工作站（源码工程）

一个只在自己电脑上使用的本地工作生活管理软件。WPF 桌面程序，不需要登录、不联网、不上传任何数据。

## 运行环境

- Windows 10 / 11
- .NET 8 桌面运行时（本机已安装；如果换电脑，装一次 `dotnet-sdk-8` 或 `.NET Desktop Runtime 8` 即可）
- 不需要任何第三方包，离线可编译

## 目录结构

```
个性化工作站-源码\
├─ PersonalWorkstation.sln          解决方案文件（VS Code / Visual Studio 2022 都能打开）
├─ .vscode\                         VS Code 调试与任务配置
│   ├─ launch.json                  按 F5 直接调试（数据写到 .dev-data）
│   └─ tasks.json                   生成 / 发布任务
├─ publish.ps1                      一键编译并发布 exe 到 ..\个性化工作站
└─ PersonalWorkstation\             程序本体
    ├─ App.xaml / MainWindow.xaml   应用入口与主窗口（顶栏 + 导航 + 标签页 + 状态栏）
    ├─ Models\AppData.cs            全部数据模型（9 个模块）
    ├─ Services\
    │   ├─ DataStoreService.cs      数据文件读写、原子替换、备份、恢复、导入
    │   ├─ ThemeService.cs          浅色 / 深色 / 跟随系统
    │   ├─ LogService.cs            本地错误日志（logs 目录）
    │   ├─ SelfTest.cs              数据层自检（命令行 --selftest）
    │   └─ UiSnapshot.cs            界面截图自检（命令行 --uicheck）
    ├─ ViewModels\                  导航、标签页、保存状态等界面状态
    ├─ Views\                       页面（当前是占位说明页 + 已完成的「数据与设置」页）
    └─ Resources\                   配色与控件样式
```

## 怎么运行

**Visual Studio 2022**：打开 `PersonalWorkstation.sln`，按 F5。

**VS Code**：打开本文件夹（不是它的上级目录），按 F5。需要装 C# 扩展（C# Dev Kit）。

**命令行**：

```powershell
dotnet run --project .\PersonalWorkstation\PersonalWorkstation.csproj
```

**发布成一个 exe**（在 PowerShell 里运行）：

```powershell
.\publish.ps1
```

发布结果在 `..\个性化工作站\`，双击里面的 `PersonalWorkstation.exe` 即可使用。

## 数据存在哪

程序目录下的 `data\工作站数据.json`，旁边 `backups\` 是自动备份目录。

- 每次改动后 500 毫秒自动写盘，关窗口、重启电脑都不会丢。
- 程序启动和退出时，如果数据有变化会自动备份一份，最多保留最近 60 份。
- 恢复备份或导入之前，都会先把当前数据另存一份，所以操作可以回退。
- 数据文件损坏时会自动用最近备份恢复，并把坏文件另存一份留底。
- 把整个程序文件夹复制走，就是一份完整备份。

## 命令行开关（开发用）

| 参数 | 作用 |
| --- | --- |
| `--data-dir <目录>` | 指定数据目录（调试时用，不影响正式数据） |
| `--selftest [报告文件]` | 跑数据层自检，退出码 0 表示全部通过 |
| `--uicheck <目录>` | 把每个模块、每个标签页渲染成 PNG，用于检查界面 |
